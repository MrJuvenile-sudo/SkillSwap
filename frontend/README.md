# SkillSwapX Frontend

Modern, fast, and responsive React + Vite single page application for SkillSwapX.

## Features
- **Intelligent Peer Matching**: Dynamic reciprocal skill match scoring and recommendations.
- **Interactive Explore Dropdown**: Seamless hover and click navigation across all skill categories.
- **Animated Hero Section**: Smooth flowing particle canvas with dynamic peer profiles that update on page load.
- **Direct Messaging & Exchange Hub**: Scheduling, reviews, learning circles, and real-time chat.
- **Responsive Layout**: Designed for mobile, tablet, and desktop with dark/light theme support.

## Getting Started

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```
